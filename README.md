# 33業種スキャン（デイトレ向きセクター・銘柄探し）

東証プライムの値動きを33業種ごとに集計し、各業種の中で値幅が大きく売買が活発な銘柄をCSVに出力します。

- データ元：Yahoo Finance（yfinance）※東証は**約20分遅延**
- 業種区分：JPX「東証上場銘柄一覧」の33業種区分（7日ごとに自動で再取得）
- 業種の騰落率は構成銘柄の**単純平均**です。公式の東証業種別株価指数（時価総額加重）とはずれることがあります。

## モード

| モード | 対象 | 実行のめやす |
|---|---|---|
| morning（朝） | プライム全銘柄の**前日**データ。売買代金上位リストも作る | 寄り前（〜9:00） |
| yori（寄り後） | 同上の寄り付き後データ（約20分遅延のため9:30実行で9:10ごろまで） | 9:30 |
| zenba（前場後） | 朝に作った売買代金上位銘柄（既定300）の当日前場データ | **11:50以降** |
| close（大引け後） | 同上の大引けデータ | **15:50以降** |
| auto | 実行時刻から自動判定（〜9:00朝／〜10:30寄り後／〜12:30前場後／それ以降は大引け後） | — |

前場後・大引け後を使う日は、先に朝モードを実行しておいてください（上位リストが更新されます）。

## 出力（data/ フォルダ）

- `YYYY-MM-DD_<mode>_sectors.csv`：業種ごとの集計（騰落率順。上位3・下位3・±2%以上に印）
- `YYYY-MM-DD_<mode>_stocks.csv`：銘柄ごとの指標（業種順位 → 日中値幅の大きい順）
- `latest_<mode>.md`：Claudeの日本株レポートが読むまとめ（ウォッチリストの数値、値幅の大きい銘柄）。毎回上書き
- 実行画面（Actionsのサマリー）にも、上位・下位業種と値幅の大きい銘柄の一覧が表示されます

### ウォッチリスト

`watchlist.txt` に書いた銘柄は、上位300に入っていなくても毎回対象に含めます。「日本株」プロジェクトの設定ファイルのウォッチリストと同じ内容にそろえてください。

前場後モードは5分足から11:30までの値を作り直すので、実行が遅れて後場にかかっても前場の値になります。

## 主な項目
- **日中値幅%**：(高値−安値)÷前日終値。動いた幅の大きさ
- **ATR14%**：過去14日の平均的な1日の値幅
- **値幅/ATR**：今日の値幅がふだんの何倍か（1超＝いつもより動いている）
- **出来高倍率**：今日の出来高 ÷ 過去20日平均。※前場後は「前場の出来高 ÷ 1日平均」なので小さく出ます
- **売買代金_億円**：(高値+安値+終値)/3 × 出来高 の概算

## 初回セットアップ（PCで1回だけ）

1. このフォルダをGitHub Desktopで「Add local repository」→「Publish repository」（Privateで可）
2. GitHubのリポジトリ画面 → Settings → Actions → General → Workflow permissions を **Read and write** にする

## スマホからの実行

1. スマホのブラウザ（またはGitHubアプリ）でリポジトリを開く
2. **Actions** → **33業種スキャン** → **Run workflow** → モードを選んで実行（通常は auto のままでOK）
3. 数分で完了。実行結果の画面にサマリーが表示され、CSVは `data/` フォルダに保存されます

## PCで直接実行する場合

```
pip install -r requirements.txt
python scan.py --mode auto
```

オプション：`--top 300`（上位リストの銘柄数）、`--min-turnover 10`（サマリーに載せる銘柄の売買代金下限・億円）、`--refresh-universe`（銘柄一覧の再取得）

## 注意
- Yahoo Financeが混雑していると一部銘柄の取得に失敗することがあります（失敗分は1回自動で再試行）
- 祝日は当日データがないため、サマリーに「休場日の可能性」と表示されます
- 売買の推奨をするものではありません。セクター・銘柄を絞り込むための材料です
